🔒 Local-only — on this device

Ticket content never leaves this browser.

No AI provider · No server · No tracking · Works offline · Verify: Network tab → 0 requests

All priority analysis is performed locally using deterministic JavaScript rules. Ticket content is not sent to an AI provider, server, analytics platform or third party.

  • No fetch(), XMLHttpRequest, WebSocket or sendBeacon calls exist in this application.
  • No account, sign-in or API key is required.
  • Ticket text is held in memory only and disappears when you refresh or close the page.
  • No cookies, analytics, telemetry or tracking are used, and no external fonts, scripts or stylesheets are loaded.

This page is served over the network like any other web page. The accurate claim is not that no network exists — it is that your ticket content never leaves the browser. You can verify this in your browser's developer tools: open the Network tab, analyse a ticket, and observe that no request is made.
